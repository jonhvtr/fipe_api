🔍 FIPE Consumer API

Aplicação Spring Boot em Java que consome a FIPE API (v2) para consulta de preços e informações de veículos (marcas, modelos, versões, anos, etc).
Essa aplicação serve como um “wrapper” ou cliente próprio para a FIPE, podendo transformar, cachear ou adaptar os dados conforme suas regras de negócio.

📚 Tecnologias

- Java 17

- Spring Boot

- Jackson para conversão JSON

- Maven

🧩 Funcionalidades Principais

- Buscar marcas de veículos por tipo (carro, moto, caminhão)

- Listar modelos de uma marca

- Listar anos / versões de um modelo

- Obter detalhes / preço FIPE de um veículo específico
